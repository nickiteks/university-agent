Скилл: подготовка пакета на внутренний научный проект
process_id: prepare_internal_research_application

Описание:
Пользователь просит подготовить пакет документов для подачи заявки на внутренний научный проект.

Доступные tools бизнес-процесса:
- auth_context: получить auth context из security слоя и остановиться, если пользователь не авторизован.
- detect_intent: понять намерение пользователя и тип проекта.
- search_knowledge: найти доступные пользователю регламенты, шаблоны и инструкции.
- check_requirements: проверить требования для типа проекта.
- list_missing_documents: составить список недостающих документов.
- prepare_application_structure: подготовить структуру заявки.
- prepare_tasks: подготовить задачи соавторам, но создавать их только после подтверждения.
- prepare_email_draft: подготовить черновик письма на согласование, но не отправлять его.
- quality_check: проверить, что ответ содержит источники и не ссылается на закрытые документы.
- write_audit: записать действия в аудит и собрать итоговый ответ.

Рекомендуемая последовательность для полного пакета:
auth_context -> detect_intent -> search_knowledge -> check_requirements -> list_missing_documents -> prepare_application_structure -> prepare_tasks -> prepare_email_draft -> quality_check -> write_audit

Правила:
- auth_context всегда должен быть первым tool в плане.
- write_audit должен завершать успешно выполненный бизнес-процесс.
- Если пользователь просит только часть работы, можно выбрать подмножество tools, но не пропускай tools, от которых зависят следующие действия.
- Если tool не может продолжить без данных или подтверждения, он сам вернёт interrupt.
